# Описание задачи

> Формат **Дано:** / **Когда:** / **Тогда:** используется для контроля покрытия: каждой проверке «Тогда» в feature-сценарии обязан соответствовать содержательный проверяющий шаг (value-ассерт).

## Тест 01: Ввод начальных остатков и перемещение товара

**Дано:**
- Товар «Материал без характеристики» уже существует в тестовой базе (создавать НЕ нужно).
- Склады «Оптовый неордерный» и «Магазин неордерный» уже существуют в тестовой базе (создавать НЕ нужно).
- Поставщик «Поставщик1» уже существует в тестовой базе (создавать НЕ нужно).

**Когда:**
- Вводим начальные остатки товара документом «Приобретение товаров и услуг»: товар «Материал без характеристики», склад «Оптовый неордерный», поставщик «Поставщик1».
- Проверяем отчёт «Остатки и доступность товаров».
- Оформляем документ «Заказ на перемещение» на половину (50%) введённого количества товара со склада «Оптовый неордерный» на склад «Магазин неордерный».
- Выполняем команду «Отгрузить» по заказу (в документе или в форме списка документов «Заказ на перемещение») и записываем документ.

**Тогда:**
- В отчёте «Остатки и доступность товаров» появились остатки на складе «Оптовый неордерный».
- Количество товара в отчёте соответствует количеству, введённому в документе «Приобретение товаров и услуг».
- По заказу на перемещение выполнен этап отгрузки.
- Документ «Заказ на перемещение» записан без ошибок.
